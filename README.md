# SOIA 开发设计技能库

面向软件与文档设计工作的可复用技能集，覆盖 Open Design、Archify、draw.io/Visio 与 OfficeCLI 工作流。

## 技能目录

| 技能名 | 一句话简介 |
|---|---|
| `soia-dev-archify-diagrams` | 使用 Archify 生成可维护的架构、数据流和流程图及 PNG 预览。 |
| `soia-dev-design-explorer` | 基于 Open Design 探索高保真 HTML 原型、设计变体、幻灯片与动画。 |
| `soia-dev-draft-prd` | 从一句话需求起草 PRD，并梳理目标、用户故事、范围、验收标准与风险。 |
| `soia-dev-drawio-visio-diagrams` | 安全转换、盘点并升级 Visio VSDX 为可编辑 draw.io 图表。 |
| `soia-dev-officecli-ops` | 使用 OfficeCLI 安全读取、复制修改并验证 DOCX、XLSX 和 PPTX。 |
| `soia-dev-open-design-ops` | 管理 Open Design 环境、项目接入、资源查询、导出与会话恢复。 |

## 安装

使用以下模板安装指定技能：

```bash
npx skills add soia-team/soia-open-dev-design-skills -g -a '*' -s <技能名> -y
```

例如，安装 Archify 图表技能：

```bash
npx skills add soia-team/soia-open-dev-design-skills -g -a '*' -s soia-dev-archify-diagrams -y
```
