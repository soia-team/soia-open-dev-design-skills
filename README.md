# SOIA 开发设计技能库

开发-设计：Open Design 两层、Archify、draw.io/Visio、OfficeCLI 文档产线（soia-dev-*）

## 域说明

本仓负责 `dev` 域，技能名称统一使用 `soia-dev-*` 前缀。

## 安装

```bash
npx skills add soia-team/soia-open-dev-design-skills -g -a '*' -s <skill> -y
```

本仓属于 SOIA 技能生态，规范真源见 [soia-team/soia-open-skills](https://github.com/soia-team/soia-open-skills)。
